# Contributing

This repository is the **OGC / MAAP DPS packaging layer** only.
Science changes belong in [NASA-IMPACT/veda-black-marble](https://github.com/NASA-IMPACT/veda-black-marble).

For packaging fixes: edit `build.sh`, `run.sh`, `resolve_earthdata_token.py`, configs, or `workflows/`, then open a PR against this repo.
